常见问题 解答

这里汇总了关于 MAGIL 的高频疑问，如果还有未覆盖到的，欢迎反馈。

高频问题

MAGIL 的自动化功能篡改或注入了游戏数据吗？
MAGIL 仅使用系统开放的自动化输入接口，不修改游戏内存或数据。但请合理使用，任何在演奏竞技中使用 MAGIL 自动演奏或伪装真人演奏的行为都是被坚决抵制的。
支持哪些系统平台？
目前 MAGIL 提供 Windows 桌面端（最新 MAGIL 4.0）和 Android 移动端（最新 MAGILM4.1）。macOS 与 HarmonyOS 版本暂未考虑，请关注后续更新。
如何安装 MAGIL？
Windows: 下载 .zip 压缩包，解压后解压文件夹内双击 MAGIL.exe 运行（推荐用管理员权限运行）。
Android: 下载 .apk 文件，在手机中安装。
MAGIL 支持哪些琴谱格式？琴谱从哪里来？
支持 指尖谱 和 呱呱谱 两种主流文本格式。也支持自研的 建筑谱 和经过一些处理的 MIDI谱。视频平台社区提供了大量琴谱，但请尊重制谱的劳动成果，在必要时声明琴谱来源。
遇到崩溃或 Bug 怎么办？
请将崩溃或 Bug 描述提交至 GitHub Issues，或通过 Bilibili 私信作者。MAGIL会尽快排查和修复。
如何参与贡献？
MAGIL 完全开源，欢迎任何形式的贡献：代码、文档、翻译、琴谱、UI 设计等。你可以在 GitHub 上点 Star、提 Issue 或提交 Pull Request，也可以通过 Bilibili 与作者交流。
MAGIL 是免费的吗？
完全免费。MAGIL 使用 GNU General Public License v3.0 (GPLv3) 许可证。这意味着你可以自由使用、修改和分发本软件，但任何修改后的版本也必须以相同的许可证开源。MAGIL 永远保持开源和免费。
在哪里可以获取最新版本？
最新版本发布在 GitHub Releases 页面，你也可以关注作者的 Bilibili 账号获取更新通知。作者主页：github.com/qinmingming16
