概述

原琴辅助演奏 MAGIL（Magical Assistant for Genshin Impact's Lyre）是一个基于系统自动化接口、完全开源且免费的音乐辅助工具。它旨在为所有对虚拟乐器演奏感兴趣的玩家提供模拟原琴、琴谱编辑、自动演奏、按键映射等核心能力，在满足大部分玩家需求的同时保持极低的上手门槛。

项目由 @秦明明 于 2024 年发起并全权维护，所有源码与资源均托管在 GitHub 上，遵循 GPLv3 许可证，在遵守对应开源许可证前提下，任何人均可使用、修改和分发。

开源 双端支持 完全免费

安装与配置

MAGIL 提供 Windows 桌面端 和 Android 移动端 两个版本。请根据你的设备选择对应安装包。

Windows 桌面端（最新MAGIL4.0）

下载 .zip 压缩文件，解压并在解压的文件夹中双击运行 .exe 文件即可。

Android 移动端（最新MAGILM4.1）

下载 .apk 文件，在手机中安装。按提示开启权限以启用对应功能。

核心功能详解

模拟原琴

无需启动游戏，直接在 MAGIL 中打开模拟原琴界面。它完整复刻了游戏内乐器的键位布局与音色，是练习指法、扒谱的绝佳环境。

琴谱编辑

MAGIL 内置 琴谱编辑器，支持两种主流文本琴谱格式：指尖谱和 呱呱谱。编辑器提供播放预览、基本语法检查，让编谱变得直观而高效。

自动演奏

基于系统开放的自动化输入接口，MAGIL 可以自动“弹奏”你提供的琴谱。你只需要选择乐谱，点击播放，即可在游戏中听到完整的演奏。整个过程无需额外驱动或复杂配置。

映射与适配

针对 Windows 和 Android 的不同输入机制，MAGIL 提供了定制映射方案。你可以将琴键映射到键盘的任意按键，或为触屏设备调整点击区域。你可以方便地修改地修改映射规则。

泛用性

除了原神，MAGIL 还支持多款包含乐器演奏的游戏。通过相同的配置方法，你可以快速适配不同游戏的键位布局。
